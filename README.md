## 🎮 What is SurvivalRaceRebuilt?

SurvivalRaceRebuilt is a fast-paced arcade racing survival game built in Unity. Drive on a hexagonal arena while tiles fall away beneath you — ram other cars off the edge and be the last one standing!

### Features
- 🔷 Procedurally generated hex tile arena
- 🚗 Multiple low-poly car models
- 🤖 AI opponents
- 💥 Car collision and push mechanics
- 🟩 Tiles fall when driven over
- 🏁 Last car standing wins

2. Download the latest `.zip` file
3. Extract the zip
4. Run `SurvivalRaceRebuilt.exe`
5. No install required

### Controls
| Key | Action |
|-----|--------|
| A / ← | Turn Left |
| D / → | Turn Right |
| W | Flight Enable/Disable |
| S | Flight Disable/Enable |

## 🔧 Building from Source

**Requirements:**
- Unity **2022.3.24f1** (LTS)
- DOTween (HOTween v2) — Free on Asset Store
- Cinemachine — via Package Manager

**Steps:**
1. Clone the repo: `git clone https://github.com/Israel28/SurvivalRaceRebuilt.git`
2. Open Unity Hub → Add project from disk → select the cloned folder
3. Open with Unity 2022.3.24f1
4. Open `Assets/Scenes/SampleScene`
5. Hit Play
